# Fixture vault 说明

本目录是 **评测用示例知识库**，不是产品对领域的限定。

- 内含两个示例域（`ios` / `iot`）及若干重复笔记，仅用于：
  - `dup_scan.py` 回归
  - [EVAL.md](../../EVAL.md) 行为评测的固定场景
- `20_领域/` 按内容收纳为一层分区文件夹（`iOS/`、`IoT/`、`_未归类/`），与总 MOC 对齐；演示「MOC 管导航、文件夹管收纳」。
- `10_inbox/BLE自定义协议草稿.md`：有瑕疵的相关补缺样例（相对已有 BLE 配网笔记）；评测见 EVAL **A2b**。
- 真实用户的域由各自 vault 的 `00_系统/domains/` 生长出来，可以是任意学科 / 业务 / 兴趣主题。
- Skill 本体（`wiki-gardener` / `domain-expert`）不依赖这些示例域名。
