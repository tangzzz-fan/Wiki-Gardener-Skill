# Persona：自媒体工作者

> 适用画像：以内容为主业的创作者（图文 / 短视频 / 多平台分发），
> 选题焦虑是日常，数据复盘是命脉，平台规则追着人跑。
> 用法：setup-wizard 第零轮选中本 persona 后，预填项降级为确认题——
> 展示给用户改，而不是让用户从零写。**北极星必须用户亲口确认，persona 只给候选。**

## 北极星候选（供用户修改）

- 「三年后这个库是我的选题与方法论资产库：不再选题焦虑，每个爆款都有可复制的依据」
- 「这个库记得我每次内容实验的结果，让运气变成概率」

## 收录标准种子

- 收：自己的选题卡与数据复盘（失败的内容同样收——负样本最值钱）
- 收：爆款拆解（必须拆到"为什么成立"的结构层，不是"这条火了"的感慨）
- 收：平台规则变化的实测记录（含日期——运营知识半衰期极短）
- 收：自己的文案/脚本原稿与修改痕迹（修改理由是核心资产）
- 不收：网上搬运的"运营技巧"合集（无自己数据佐证的一律标 [警告]）
- 不收：热点流水账（追过的热点没有沉淀为方法论的，不留）
- 不收：他山之石类的截图囤积（"这个不错先存着"是收藏夹癌症）

## 笔记类型模板

- **选题卡**：选题 / 目标人群痛点 / 钩子 / 平台适配 / 数据回填位
- **爆款拆解卡**：原内容 / 结构拆解（钩子-留存-转化）/ 可复制点 / 我的改造方案
- **数据复盘卡**：发布内容 / 核心指标 / 归因猜测（显式标注是猜测）/ 下一步实验
- **脚本迭代卡**：原稿 / 修改 / 修改理由 / 发布后数据验证

## 访谈变体（第零轮选中后替换默认问题）

- Q4 替换为：「发我一条你做过的最满意的内容（或复盘），和一条你想不通为什么扑了的」
- Q5 替换为：「你的内容领域里，有什么是你坚决不做的？（比如：不追某类热点 / 不做某类标题党 / 不露脸）」
- Q7 追加：「你主战场是哪个平台？更新频率多少？」——决定加载哪个运营域种子

## 度量权重

- 重点盯 **腐烂扫描**（平台规则月度级变化，运营知识过期即误导）
- 其次盯 **inbox 滞留**（创作灵感转瞬即逝，入口慢一天就丢选题）
