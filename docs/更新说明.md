# 更新说明（给已安装用户）

> Skill 文件会随 `npx skills update` 刷新；**vault 内** `00_系统/技能包说明.md` **不会自动改**。  
> 要看见新 companion 与触发语，更新后请再跑一次 setup（见下）。

## 本次值得知道的改动（companion）

本包在核心三件套之外，增加了可选协作 skill：

| 你想做的事 | 可以说 | Skill |
|---|---|---|
| 选题/主张还很糊，想先想清楚 | 「帮我 grill 一下这个想法」 | `grill-me` |
| 不确定选题是否真打中人 | 「这个选题能不能打中人」 | `topic-resonate` |
| 选题过了，怎么做成内容 | 「帮我做内容诊断」 | `content-diagnose` |
| 口播怕划走 | 「检查这段口播哪里会划走」 | `script-flow` |
| 拆一条对标 | 「按我的标准拆解这条对标」 | `content-decomposer` |
| 专家审后需要逐条修改 | 「按审查报告修订这篇草稿」 | `review-reviser` |
| 用已入库知识检查理解、复习错题 | 「考我 / 知识测验 / 理解检查 / 错题复习」 | `knowledge-quiz` → `00_系统/学习记录/` |
| 看知识结构与掌握关系 | 「知识地图 / 思维导图 / 结构化理解 / 掌握地图」 | `knowledge-map` → `90_export/` |
| 中文外化 / 去 AI 味 / 活人感改稿（视觉呈现之前） | 「把这篇外化成中文长帖 / 去AI味 / 中文改稿」 | `human-writing` → `90_export/` |
| 导出演示 / 配图 / 封面（可软建议先外化） | 「做成 HTML 演示 / PPT 转换 / PDF 导出 / 配图 / 封面」 | 呈现类 → `90_export/` |

完整流程：[companion协作流程.md](./companion协作流程.md)

## 更新后怎么得到提示（三步）

```bash
npx skills@latest update -g -y
```

然后在 Agent 里说：

```text
运行 setup-knowledge-skills
```

或：「我刚更新了知识库技能，刷新一下技能包说明」。

Setup 会：

1. 探测本机已装 / 未装的 companion  
2. **重写或更新** vault 的 `00_系统/技能包说明.md`（含「更新提示」「选题创作」固定节）  
3. 用一句话说清：选题糊时先 grill；已入库知识可走「测验 → 学习记录 → 知识图」支路

## 选题创作时怎么用 grill-me（复制即用）

```text
我想做一个选题，但还没想清楚。帮我 grill 一下：
（用一两句话写下模糊想法）
```

Grill 结束后你会得到「共识提纲」。再说：

```text
以〈领域〉专家身份，按刚才的共识提纲写成笔记
```

落到 `10_inbox/` 后再审、再「整理 inbox」。

审查结论需要修改时，可选装 `review-reviser`：

```bash
npx skills@latest add tangzzz-fan/Wiki-Gardener-Skill -g -y --skill review-reviser
```

它只按已批准的 finding 修改草稿；high 项修后仍要交领域专家复审。

学习 companion 可选装：

```bash
npx skills@latest add tangzzz-fan/Wiki-Gardener-Skill -g -y \
  --skill knowledge-quiz --skill knowledge-map
```

测验记录进 `00_系统/学习记录/`，不进 `10_inbox/`；知识图只读汇总并导出到 `90_export/`，不修改掌握状态。

## 若 update 后仍没有 grill-me

可能只装了核心三件套。选装思考链：

```bash
npx skills@latest add tangzzz-fan/Wiki-Gardener-Skill -g -y \
  --skill grill-me --skill topic-resonate --skill content-diagnose \
  --skill script-flow --skill content-decomposer
```
