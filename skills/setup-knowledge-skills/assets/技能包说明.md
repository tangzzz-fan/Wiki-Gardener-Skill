## 更新提示（固定节，更新后必读）

本包除园丁 / 专家外，可选用 **companion** 做「想清楚」和「导出呈现」。

- **选题 / 主张还糊**：先说「帮我 grill 一下这个想法」→ `grill-me`（一次一问 + 推荐答案 → 共识提纲），再叫领域专家成文  
- **怀疑选题只是表面成立**：说「这个选题能不能打中人」→ `topic-resonate`  
- **选题过了问怎么做**：→ `content-diagnose`；口播逻辑 → `script-flow`；对标 → `content-decomposer`  
- **审查结果要求修改**：说「按审查报告修订这篇草稿」→ `review-reviser`；高优先项修后回专家复审
- **成稿要演示 / 配图 / 封面**：呈现 companion，产物进 `90_export/`，不进 `20_领域/`  

仓库说明：[docs/更新说明.md](https://github.com/tangzzz-fan/Wiki-Gardener-Skill/blob/main/docs/更新说明.md) · [docs/companion协作流程.md](https://github.com/tangzzz-fan/Wiki-Gardener-Skill/blob/main/docs/companion协作流程.md)

## 选题创作怎么用（固定节）

1. 模糊想法 → 「帮我 grill 一下：……」  
2. （可选）「这个选题能不能打中人」  
3. 「以 〈域〉 专家身份按共识提纲写成笔记」→ `10_inbox/`  
4. 「审一下」→ 若需修改则「按审查报告修订」→ 必要时复审
5. 「整理 inbox」吸附
6. （可选）导出演示 / 配图 / 封面 → `90_export/`

## 技能分工

| Skill | 职责 |
|---|---|
| wiki-gardener | 初始化、吸附、园艺（该不该收、放哪、重不重） |
| domain-expert | 单篇执笔 / 审查（对不对） |
| setup-knowledge-skills | 安装后 / 更新后引导；日常可忽略 |

### Companion（只写本机已装；未装标「未装」，勿唤起）

| Skill | 类 | 职责 | 本机 |
|---|---|---|---|
| grill-me | 思考 | 成文前追问，收成共识提纲 | {{STATUS_grill-me}} |
| topic-resonate | 思考 | 选题/文稿是否真击中受众 | {{STATUS_topic-resonate}} |
| content-diagnose | 思考 | 选题通过后怎么做成好内容（诊断不代写） | {{STATUS_content-diagnose}} |
| script-flow | 思考 | 口播/脚本逻辑延续 | {{STATUS_script-flow}} |
| content-decomposer | 思考 | 对标拆解；产物可进 `10_inbox/` | {{STATUS_content-decomposer}} |
| review-reviser | 修订 | 按专家审查报告逐条修改并交回复审 | {{STATUS_review-reviser}} |
| frontend-slides | 呈现 | HTML 演示导出 → `90_export/` | {{STATUS_frontend-slides}} |
| ian-xiaohei-illustrations | 呈现 | 正文配图（有 mcp-image 可直出） | {{STATUS_ian-xiaohei-illustrations}} |
| gbro-cover-design | 呈现 | 封面提示词（有 mcp-image 可选直出） | {{STATUS_gbro-cover-design}} |

setup 填写 `本机` 列时：写成 `已装` 或 `未装`。Agent **不得**对「未装」行冒充可运行。

协作习惯：**先审对不对，再决定收不收。** 思考和修订产物留在 `10_inbox/`，不直写 `20_领域/`。呈现类导出到 **`90_export/`**。本机可选 Cursor MCP 生图/识图（`mcp-image` / `luma-vision`）由宿主配置，非本包安装依赖。仅当本库包含短视频运营 / 编导域时，再应用“存在性先于形态性”。

建议流水线：想清楚（grill / resonate / diagnose / decomposer）→ 成文入库（expert → gardener）→ 导出呈现。

## 常用触发语

- 建库：「帮我初始化一个知识库」
- 整理：「整理一下 inbox」
- 体检：「给知识库做个体检」
- 审稿：「以 \<领域\> 专家身份审一下这篇」
- 想清：「帮我 grill 一下这个想法」/ 「这个选题能不能打中人」
- 内容诊断：「选题过了，帮我做内容诊断」
- 拆对标：「按我的标准拆解这条对标」
- 口播：「检查这段口播哪里会划走」
- 修订：「按审查报告修订这篇草稿」
- 导出：「把这篇做成 HTML 演示 / PPT 转换 / PDF 导出 / 配图 / 封面」（输出到 `90_export/`）
- 刷新说明：「我刚更新了知识库技能，刷新一下技能包说明」
