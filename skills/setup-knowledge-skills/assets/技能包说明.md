## 技能分工

| Skill | 职责 |
|---|---|
| wiki-gardener | 初始化、吸附、园艺（该不该收、放哪、重不重） |
| domain-expert | 单篇执笔 / 审查（对不对） |
| setup-knowledge-skills | 仅安装后引导；日常可忽略 |
| （预留）内容运营类 companion | 平台向流程；有则按各自 SKILL 协作 |

协作习惯：**先审对不对，再决定收不收。** 产出进 `10_inbox/`，不直写 `20_领域/`。

## 常用触发语

- 建库：「帮我初始化一个知识库」
- 整理：「整理一下 inbox」
- 体检：「给知识库做个体检」
- 审稿：「以 \<领域\> 专家身份审一下这篇」

## 更新技能包（终端）

```bash
npx skills@latest update -g -y
```

不要执行 `npx skills update <仓库名>`（会找不到）。手拷安装的用户需先改走 `npx skills add` 才进入更新轨道。
